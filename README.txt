# Ne Önerirsin? — gerçek backend demo

Bu paket ek kütüphane gerektirmez. Python 3 yeterlidir.

Çalıştır:
    python server.py

Tarayıcı:
    http://127.0.0.1:8000

Gerçekten çalışanlar:
- soru paylaşma
- SQLite veritabanına kaydetme
- yorumları açma
- yorum yazma
- yorumların SQLite'a kaydolması
- profil ekranı
- kendi paylaşımlarını profilde gösterme

İnternete açmak için bu klasörün bir Python hostingine yüklenmesi gerekir.
Başlatma komutu:
    python server.py
